## Ghost404

Clean, lightweight 404 page with subtle animations ✨👻 Built with Tailwind CSS + Lucide. Drop-in fallback for any site, easy to customize.

![Preview](assets/preview.png)

<img src="assets/readme-icons/link.png" alt="Link" width="20" height="20" style="vertical-align: middle; margin-right: 6px;"> **Live Demo:** [www.zxtni.app/404/](https://www.zxtni.app/404/)

<img src="assets/readme-icons/info.png" alt="Info" width="20" height="20" style="vertical-align: middle; margin-right: 6px;"> **About**
Clean, animated 404 page built with Tailwind CSS and Lucide icons. Drop it into any static site or route fallback.

<img src="assets/readme-icons/bolt.png" alt="Quick Start" width="20" height="20" style="vertical-align: middle; margin-right: 6px;"> **Quick Start**
- Open `404.html` in your browser or serve it from your web server as the 404 fallback.

<img src="assets/readme-icons/tools.png" alt="Tools" width="20" height="20" style="vertical-align: middle; margin-right: 6px;"> **Tech**
- **Tailwind CSS** via CDN
- **Lucide** icons via CDN
